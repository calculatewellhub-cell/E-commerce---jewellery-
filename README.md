# Aurelia Jewels: luxury jewellery e-commerce

A production-ready **Next.js 16** storefront for a fine jewellery business. It includes:

| Feature | Where |
|---|---|
| **Luxury design**: emerald-and-gold theme, serif typography, scroll reveals, 3D tilt cards | `app/globals.css`, `components/` |
| **Real-time 3D jewellery** (three.js): physically based gold and a refractive brilliant-cut diamond, drag to rotate | `components/JewelViewer.tsx` (home hero, "View in 3D" on every product) |
| **WhatsApp ordering**: one-tap "Order on WhatsApp" with the full order (items, sizes, SKU, total, address, order ref), enquiries, video-call requests and a floating chat button | `lib/whatsapp.ts`, `components/BuyBox.tsx`, `components/CartPage.tsx` |
| **AI chat concierge "Aria"** (Claude): recommends products from the catalogue with links, answers gold and diamond questions, hands off to WhatsApp with the transcript. Falls back to a built-in rule-based assistant when no API key is set | `app/api/chat/route.ts`, `lib/concierge.ts`, `components/ChatWidget.tsx` |
| **SEO & AIO**: per-page metadata, canonical URLs, Open Graph image, JSON-LD (JewelryStore, WebSite+SearchAction, Product with Offer/shipping/returns/ratings, BreadcrumbList, ItemList, FAQPage), sitemap with images, robots that welcome AI crawlers (GPTBot, ClaudeBot, PerplexityBot…), `llms.txt` + `llms-full.txt`, Google Merchant / Meta catalogue feed | `app/sitemap.ts`, `app/robots.ts`, `app/llms.txt`, `app/feed.xml`, `app/opengraph-image.tsx` |
| **Image → Video Studio**: turns product photos into branded Reels/Stories/Shorts (9:16, 1:1, 16:9) with Ken Burns, fade, slide or gold-shine transitions, titles, prices, CTA and optional music. Renders MP4/WebM in the browser | `/admin` → Video Studio (`components/admin/VideoStudio.tsx`) |
| **Social auto-posting**: compose, write captions and hashtags with AI, schedule or publish to Instagram, Facebook, Pinterest, X, LinkedIn, YouTube and WhatsApp Channel via a Make/Zapier/n8n webhook, or directly to Facebook and Instagram through the Meta Graph API | `/admin` → Social Posting, `lib/social.ts` |
| **Tracking & analytics**: page views with traffic source/UTM, product views, add-to-bag, WhatsApp orders and value, chat usage, and tracked short links per post and platform (`/go/<id>?p=instagram`) | `/admin` → Analytics, `lib/analytics.ts` |

## Quick start

```bash
npm install
cp .env.example .env.local   # then fill in the values
npm run dev                  # http://localhost:3000
```

The admin studio is at **`/admin`**. Set `ADMIN_PASSWORD` in `.env.local` first.

## Configuration (`.env.local`)

| Variable | Purpose |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | Your live domain (canonical URLs, sitemap, JSON-LD, tracked links) |
| `NEXT_PUBLIC_WHATSAPP_NUMBER` | WhatsApp Business number, digits only with country code (e.g. `919876543210`) |
| `ANTHROPIC_API_KEY` | Enables the Claude-powered concierge and AI captions (optional) |
| `ANTHROPIC_MODEL` | Optional model override (default `claude-opus-5`) |
| `ADMIN_PASSWORD` | Protects `/admin` and the admin APIs |
| `SOCIAL_WEBHOOK_URL` | **Recommended.** Make.com, Zapier or n8n webhook that receives each post and fans it out to every network |
| `META_PAGE_ID`, `META_PAGE_ACCESS_TOKEN`, `META_IG_USER_ID` | Post directly to a Facebook Page and an Instagram Business account |
| `CRON_SECRET` | Protects `/api/social/cron`, which publishes scheduled posts |

### Social posting webhook payload

```json
{
  "id": "post-id",
  "brand": "Aurelia Jewels",
  "mediaUrl": "https://…/reel.mp4",
  "mediaType": "video",
  "link": "https://yoursite.com/product/…",
  "posts": [{ "platform": "instagram", "caption": "…", "trackedLink": "https://yoursite.com/go/post-id?p=instagram" }]
}
```

In Make/Zapier, add a router with one branch per `platform`.

### Scheduled posts

`vercel.json` calls `/api/social/cron` every hour on Vercel; Vercel sends `CRON_SECRET` automatically. On other hosts, use any cron service:

```bash
curl -H "Authorization: Bearer $CRON_SECRET" https://yoursite.com/api/social/cron
```

### Data storage

Posts and analytics are saved as JSON in `.data/`, which works on any Node server (VPS, Render, Railway, Docker). **Serverless hosts such as Vercel have no persistent disk.** There the app falls back to `/tmp`, which gets wiped. For production on those hosts, swap the two functions in `lib/store.ts` for a database such as Supabase, Postgres or Upstash Redis.

## Customising

- **Products and categories:** `lib/products.ts`
- **Store details** (name, address, phone, socials, currency): `lib/site.ts`
- **Product images:** the SVG artwork in `public/images/products/` is placeholder art generated by `scripts/generate-images.mjs`. Replace it with real photography (same file names, or change the `image` field). Real photos also make the videos from the Video Studio look their best.

## Deploy

Works on Vercel, Netlify, Render or any Node host:

```bash
npm run build && npm start
```

After deploying, submit `https://yoursite.com/sitemap.xml` in Google Search Console, and `https://yoursite.com/feed.xml` in Google Merchant Center or Meta Commerce Manager.
